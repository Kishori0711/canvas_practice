# canvas_practice

HTML Canvas, Tailwind CSS aur JavaScript se bane design experiments. Har design apne alag folder me hai.

## Designs

| Folder | Description |
| --- | --- |
| [canvas-playground](./canvas-playground) | Particle network, ocean sunset, flow field art, kaleidoscope drawing pad, fireworks, 3D dot sphere aur spirograph |
| [flow-3d-text](./flow-3d-text) | Animated flow field background ke upar mouse se tilt hone wala 3D extruded text, color palettes aur PNG export |
| [neon-lab](./neon-lab) | Interactive fun: particle text, Neon Breaker game, gravity balls, Matrix rain, lava lamp metaballs aur hyperspace warp |

## Kaise chalayein

Kisi bhi folder ka `index.html` browser me khol do.
